# Deadline Radar

**A student productivity dashboard that helps you organize assignments, prioritize deadlines, and build better study habits.**

Deadline Radar brings academic planning and productivity tools together in one place. It helps students see what needs attention, decide what to work on next, and stay motivated along the way.

## Features

- **Assignment Tracker:** Add assignments, courses, due dates, importance levels, and estimated completion times.
- **Smart Prioritization:** Automatically ranks assignments using deadline urgency and importance to recommend what to work on next.
- **Progress Dashboard:** Tracks total assignments, completed work, upcoming deadlines, estimated workload, and overall progress.
- **Deadline Bingo:** An interactive 3×3 challenge board that turns productive study habits into a game. Complete a row, column, or diagonal to earn Bingo.
- **AI Reality Check:** Reviews writing for common generic phrases, repetitive sentence openings, and opportunities to make writing sound more personal. This is a writing feedback tool, not an AI detector.
- **Focus Timer:** Includes 25-minute focus sessions, 5-minute short breaks, and 15-minute long breaks.

## Technologies Used

| Technology | How it is used |
|---|---|
| HTML5 | Builds the structure and content of the application. |
| Tailwind CSS | Styles the dashboard, layouts, buttons, and responsive design. |
| JavaScript | Handles assignments, prioritization, Bingo, writing feedback, and the focus timer. |
| Local Storage | Saves assignments and Bingo progress in the browser. |
| GitHub Pages | Hosts the application as a public website. |

## How It Works

Deadline Radar runs directly in a web browser. No account or installation is required.

1. Add assignments with their due dates and estimated completion times.
2. Use the dashboard to see your workload and overall progress.
3. Follow the Radar recommendation to identify your next priority.
4. Complete Bingo challenges and use the focus timer to stay productive.
5. Use the writing checker to review your writing and identify areas for improvement.

## Running the Project

**Option 1: Use the website**

Visit the published GitHub Pages website.

**Option 2: Run it locally**

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

## Important Notes

- Assignments and Bingo progress are saved using browser Local Storage. Data stays in the browser where it was created and does not automatically sync between devices.
- The writing checker uses built-in JavaScript rules to provide writing suggestions. It does not connect to an AI service or determine whether text was written by AI.
- Tailwind CSS is loaded through its CDN, so an internet connection is needed to load the styling.
